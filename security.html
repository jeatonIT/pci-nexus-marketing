Platform Security

Built to meet the same standards we help you achieve

PCI-Nexus is built with security at every layer — from database row-level security to encrypted evidence storage and MFA-enforced access.

🔒 Encryption at Rest & in Transit
All data encrypted with AES-256. All communications over TLS 1.3.
🧱 Row-Level Security
26 database tables with enforced row-level security — tenants cannot access each other's data.
🔑 MFA Enforced
Multi-factor authentication required for all users on first login and for all administrative access.
📋 Audit Logging
Every action logged with user, timestamp, and IP. Immutable audit trail for compliance evidence.
🏗️ Hosted on Vercel + Supabase
SOC 2 Type II certified infrastructure with automatic scaling and 99.9% uptime SLA.
🔐 PIN-Protected Locations
Each client location is PIN-protected. No cross-contamination between client environments.
